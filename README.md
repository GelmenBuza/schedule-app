# Расписание занятий

Мобильное приложение для просмотра расписания занятий студентов, преподавателей и кабинетов. Приложение позволяет пользователям выбирать расписание, сохранять его по умолчанию и просматривать занятия на неделю с детальной информацией.

## Особенности

- **Выбор расписания по категориям:**
  - Группы
  - Преподаватели
  - Кабинеты
- **Настройки по умолчанию:** Сохранение выбранного расписания для автоматического открытия при входе.
- **Табличный просмотр:** Удобное расписание на неделю с группировкой по дням.
- **Детальная информация о занятии:**
  - Название предмета
  - Время начала и окончания
  - Преподаватель(и) / Группа
  - Аудитория
  - Тип занятия (асинхронное/синхронное)
- **Удобная навигация:** Tab-навигация (Главная, Поиск, Настройки) с использованием Expo Router.

## Стек технологий

- **Фреймворк**: React Native с Expo
- **Навигация**: Expo Router
- **Язык программирования**: TypeScript
- **Локальное хранилище**: AsyncStorage (сохранение настроек)
- **Архитектура**: Модульная структура приложения
- **UI/UX компоненты**: React Native Reanimated, Expo Symbols, Expo Glass Effect
- **Получение данных**: Nuxt.js data parsing (через специализированный парсер `devalue`)

## Зависимости

Основные зависимости проекта:

- `expo` & `expo-router` - платформа и навигация
- `@react-native-async-storage/async-storage` - для сохранения пользовательских предпочтений
- `@react-native-picker/picker` - компонент выбора значений из списка
- `devalue` - библиотека для десериализации данных Nuxt.js
- `react-native-reanimated` & `react-native-gesture-handler` - анимации и жесты

## Запуск проекта

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение:
```bash
# Для Android
npm run android

# Для iOS
npm run ios

# Для веб-версии
npm run web

# С помощью Expo Go
npm run start
```

## API

Приложение получает данные с сервера по адресу: `https://site.mstimetables.ru/01a00f53d32773b5b396bf3eb6f57ce2`

Данные передаются в формате Nuxt.js и обрабатываются специальными парсерами (для групп, преподавателей, кабинетов и самих занятий).

## Использование

1. При запуске приложения, если расписание по умолчанию не выбрано, вы можете перейти в настройки или на экран поиска.
2. В разделе **Поиск** выберите категорию (Группы, Преподаватели, Кабинеты), затем конкретный элемент.
3. В **Настройках** можно сохранить дефолтное расписание, которое будет отображаться на главном экране при каждом запуске.
4. Расписание выводится по дням недели в удобном визуальном формате с обработкой состояний загрузки и ошибок.
